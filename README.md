## 📋 Возможности

- **📝 Полноценный Markdown-редактор** — все стандартные элементы разметки
- **👁️ Живой предпросмотр** — с синхронным скроллом (исправлен в v7.2)
- **🎤 Голосовой ввод** — диктовка текста без дублирования (Web Speech API)
- **🤖 AI-помощник (DeepSeek)** — проверка орфографии, перевод, улучшение стиля, генерация SQL и RegEx
- **🎨 Три темы оформления** — тёмная, светлая, сепия
- **📥 Экспорт** — PDF (печать), CSV, HTML
- **🔍 Поиск по тексту** — с навигацией по совпадениям
- **📋 Шаблоны документов** — статья, отчёт, TODO, баг-репорт и др.
- **💡 Сниппеты** — быстрая вставка блоков (важно, совет, код и др.)
- **↩️ Undo/Redo** — отмена и повтор действий
- **🖼️ Вставка изображений** — из буфера обмена (в т.ч. Base64)
- **📊 Статистика** — символы, слова, строки, время чтения
- **⌨️ Горячие клавиши** — ускоряют работу

## 🤖 AI-функции (DeepSeek)

Для работы AI-помощника требуется **API-ключ DeepSeek**.  
Получите его бесплатно на [platform.deepseek.com](https://platform.deepseek.com/api_keys) и вставьте в настройках приложения (⚡).

| Функция | Описание |
|:---|:---|
| 🔍 Проверить орфографию | Находит ошибки в тексте |
| 🌐 Перевести | Перевод на английский / русский |
| 📝 Суммаризировать | Краткое содержание текста |
| ✨ Улучшить стиль | Делает текст выразительнее |
| 📊 Текст в SQL | Генерация SQL на основе описания |
| 🎯 Текст в RegEx | Генерация регулярного выражения |
| 💡 Объяснить код | Поясняет, что делает код |
| 🔧 Исправить код | Ищет и исправляет ошибки |
